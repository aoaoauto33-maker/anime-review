# テーブル設計仕様書

## テーブル一覧
| No | テーブル物理名 | 論理名 | 概要 |
|---|---|---|---|
| 1 | users | 利用者 | アニメレビューを利用するユーザー |
| 2 | genres | ジャンル | ジャンル一覧 |
| 3 | animes | アニメ | レビュー対象となるアニメの情報 全体評価は各エピソードのレビュー評価を集計して算出し、DBには保存しない |
| 4 | taggings | タグ | 多対多を避けるためではなく、多対多の関係を実現するための中間テーブル |
| 5 | episodes | エピソード | アニメのエピソード一覧 |
| 6 | reviews | レビュー | 利用者がアニメの各エピソードに対して投稿する評価・感想 |
| 7 | requests | リクエスト | 【管理者向け】新規アニメ登録に対するリクエスト管理 |



## 1. users（利用者）

| カラム名 | データ型 | 制約 | 論理名 | 説明 |
|---|---|---|---|---|
| user_id | SERIAL | PRIMARY KEY | 利用者ID | 自動で値をつける |
| user_name | VARCHAR(20) | NOT NULL | 利用者名 | - |
| age | INTEGER | CHECK (age >= 0) | 年齢 | マイナスの値を防ぐ |
| gender | VARCHAR(20) | CHECK (gender In ('male', 'female','others')) | 性別 | 男性、女性、その他しか入らない |
| role | VARCHAR(20) | NOT NULL DEFAULT 'user'  CHECK (role IN ('user', 'admin')) |  userかadmin 初期値はuser |
| created_at | TIMESTAMP | NOT NULL DEFAULT CURRENT_TIMESTAMP | 利用者登録日時 | 初期値に現在時刻を入れる |
| updated_at | TIMESTAMP | NOT NULL DEFAULT CURRENT_TIMESTAMP | 利用者情報更新日時 | 利用者情報を最後に更新した日時 |



## 2. genres（ジャンル）

| カラム名 | データ型 | 制約 | 論理名 | 説明 |
|---|---|---|---|---|
| genre_id | SERIAL | PRIMARY KEY | ジャンルID | 自動で値をつける |
| genre_name | VARCHAR(50) | NOT NULL, UNIQUE| ジャンル名 | 同じジャンル名の重複登録を防ぐ |



## 3. animes（アニメ）

| カラム名 | データ型 | 制約 | 論理名 | 説明 |
|---|---|---|---|---|
| anime_id | SERIAL | PRIMARY KEY | アニメID | 手動採番 |
| anime_name | VARCHAR(50) | NOT NULL, UNIQUE| アニメ名 | 同じアニメの重複登録を防ぐ |
| image_url | TEXT | DEFAULT 'default_anime.png' | 画像URL | 初期値に無地の画像を指定 |
| anime_description | VARCHAR(200) | - | 概要 | - |
| release_year | INTEGER | NOT NULL CHECK (release_year >= 1900) | 放送年 | - |



## 4. taggings（タグ）

| カラム名 | データ型 | 制約 | 論理名 | 説明 |
|---|---|---|---|---|
| genre_id | INTEGER | PRIMARY KEY | ジャンルID | genres.genre_idを参照 |
| anime_id | INTEGER | PRIMARY KEY | アニメID | animes.anime_idを参照 |


## 5. episodes (エピソード)

| カラム名 | データ型 | 制約 | 論理名 | 説明 |
|---|---|---|---|---|
| episode_id | SERIAL | PRIMARY KEY | エピソードID | 特定のアニメと紐づいたエピソードを識別するID |
| anime_id | INTEGER | FOREIGN KEY | アニメID | animes.anime_idを参照 |
| episode_number | INTEGER | CHECK episode_number >= 1 |---| UNIQUE(anime_id, episode_number) |
| episode_title | VARCHAR(100) |---|---|---|
| episode_description | VARCHAR(200) | - | 概要 | - |
| release_date | DATE | NOT NULL | 放送日 | - |

###  テーブル制約

| 制約 | 内容 |
|---|---|
| UNIQUE (anime_id, episode_number) | 同じアニメ内で同じ話数のエピソードを重複登録できない |



## 6. reviews（レビュー）

| カラム名 | データ型 | 制約 | 論理名 | 説明 |
|---|---|---|---|---|
| review_id | SERIAL |　PRIMARY KEY | レビューID | - |
| user_id | INTEGER | FOREIGN KEY | 利用者ID | users.user_idを参照 |
| episode_id | INTEGER | FOREIGN KEY | エピソードID | - |
| rating | INTEGER | NOT NULL, CHECK rating >= 1 AND rating <=5 | 評価 | 1〜5の5段階評価 |
| comment | VARCHAR(100) | - | 感想 | - |
| created_at | TIMESTAMP | NOT NULL DEFAULT CURRENT_TIMESTAMP | レビュー投稿日時 | 初期値に現在時刻を入れる |
| updated_at | TIMESTAMP | NOT NULL DEFAULT CURRENT_TIMESTAMP | レビュー更新日時 | レビューを最後に更新した日時 |

###  テーブル制約

| 制約 | 内容 |
|---|---|
| UNIQUE (user_id, episode_id ) | 同じユーザーが同じエピソードに複数のレビューを登録することを防ぐ |



## 7. requests（リクエスト）

| カラム名 | データ型 | 制約 | 論理名 | 説明 |
|---|---|---|---|---|
| request_id | SERIAL |　PRIMARY KEY | リクエストID | - |
| user_id | INTEGER | FOREIGN KEY | 利用者ID | users.user_idを参照 |
| new_anime_name | VARCHAR(100) | NOT NULL | 新規アニメ名 | - |
| reason | VARCHAR(100) | - | 理由 | - |
| request_status | VARCHAR(10) | NOT NULL DEFAULT 'pending' CHECK (request_status IN ('pending', 'approved', 'rejected')) | ステータス | 値はpending,approved,rejectedのみ |
| created_at | TIMESTAMP | NOT NULL DEFAULT CURRENT_TIMESTAMP | リクエスト投稿日時 | 初期値に現在時刻を入れる |
| processed_at | TIMESTAMP | - | 処理日時 | 承認または却下された日時 |
